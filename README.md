# 藍色大肥魚 Discord 機器人

軟萌可愛、繁體中文的 Discord 聊天機器人（DC機器人）。會聊天（記得最近對話）、自動判斷要不要上網查資料、精確計算、找真的 YouTube 連結、身份組管理、回顧頻道紀錄、語音頻道點歌（YouTube、B 站都可以）、運動比分（中職、台灣職籃、NBA、MLB、足球…），私訊不用 @ 就能直接聊。

AI 聊天可以用**免費線上 AI**（什麼都不用申請）、**Google Gemini**、ChatGPT、Claude、DeepSeek 等線上服務，也可以用**本機 Ollama**（免費、對話不外流，但要好的顯示卡）。電腦不好也能用 AI 聊天。

還有**知識庫**：把伺服器規則、常見問題、攻略、價目表這些文件丟進「知識庫」資料夾，本魚回答時會自動找出相關段落參考，並標出資料來源。支援 txt、md、PDF、Word、Excel、PowerPoint 等格式。

## 最簡單：下載安裝程式

到 [Releases](https://github.com/Benjaminwz/bluefish-discord-bot/releases/latest) 下載：

- **Windows**：`BlueFish-Setup-Windows-版本.exe`，雙擊後照著按「下一步」。Windows 跳出「Windows 已保護您的電腦」的話，按「其他資訊」→「仍要執行」。
- **Mac**：`BlueFish-Mac-版本.zip`，解壓縮後把「藍色大肥魚」拖進「應用程式」，照裡面的 `安裝說明.txt` 打開。

安裝程式會自動下載本魚專用的 Python（不會動到電腦裡原本的 Python），裝好後打開設定視窗，一步步選 AI、貼上 Discord Token。之後要更新，下載新版安裝程式再裝一次就好，設定和資料都會保留。

下面是「整個資料夾」的用法：從 GitHub 下載原始碼，或是朋友直接把資料夾傳給你的時候。

## 第一次使用：雙擊「首次安裝.bat」

新電腦什麼都不用先裝，**雙擊 `首次安裝.bat`**，照畫面回答幾個問題就好。每一步都會先問你：直接按 Enter 就是「好」，**已經熟悉、想自己處理的步驟按 n 就會跳過**（例如自己裝過 Python、已經有架好的 SearXNG）。它會：

1. 顯示系統需求和你電腦的規格（記憶體、顯示卡、硬碟空間），綠色是夠、黃色是勉強、紅色是不夠。
2. 問你 **AI 聊天**要用哪一種：
   - **1. 免費線上 AI**：什麼都不用申請，直接按 Enter 就是這個。缺點是大家共用，常常要等 10～50 秒。
   - **2. Google Gemini（推薦）**：會幫你打開 Google AI Studio，用 Google 帳號按「Create API key」、複製、貼回來就好，大約多花 1 分鐘。有免費額度，又快又穩。
   - **3. 本機 AI（Ollama）**：免費、對話不會送出去，但要好的顯示卡，會下載 3～10 GB 的模型。
   - **4. 先不要 AI 聊天。**

   之後在控制面板的「AI 來源」分頁隨時可以換。也會問你要不要讓 AI **上網查資料**（用內建搜尋，不用另外裝東西，直接按 Enter 就好）。
3. 沒有 Python 的話自動下載安裝（不用系統管理員權限）。
4. 安裝 Python 套件、下載 ffmpeg（放音樂用）和 Deno（約 45 MB，解析 YouTube 影片用；電腦裡已經有 Node.js 的話會自動跳過）。
5. 教你建立 Discord 機器人，把 Token 貼上去就存好。
6. 有選本機 AI 的話：安裝 Ollama，並依照你的顯示卡下載適合的模型。
7. 有選「改用 Docker + SearXNG 搜尋」的話（進階，大部分人不需要）：安裝 Docker Desktop。Docker 裝好通常要重新開機，開機後打開 Docker Desktop，**再雙擊一次 `首次安裝.bat`**，就會自動建好搜尋服務（SearXNG）。
8. **做出邀請連結**：有 Token 的話直接產生（沒有的話可以貼 Application ID），自動複製到剪貼簿，並問你要不要馬上打開，把本魚加進你的伺服器。
9. 在開始功能表和桌面建立「藍色大肥魚控制面板」捷徑（本魚的大頭貼圖示），並打開控制面板。

之後都從開始功能表或桌面的「藍色大肥魚控制面板」打開就好。想放在工作列或開始畫面：在開始功能表搜尋「藍色大肥魚」，在圖示上按右鍵 →「釘選到工作列」或「釘選到開始畫面」。（`控制面板.bat` 也還能用，但它是批次檔，Windows 不讓批次檔釘選。）`首次安裝.bat` 可以重複執行，已經裝好的東西會自動跳過，缺什麼補什麼，所以之後想加裝 AI 或搜尋功能，再跑一次就好。

### 系統需求

| 功能 | 需要 |
|---|---|
| 基本功能（管理、遊戲、等級、音樂） | Windows 10 / 11 64 位元、記憶體 4 GB、硬碟 1 GB |
| AI 聊天（線上 AI） | 電腦不用好，有網路就行 |
| AI 聊天（本機 Ollama） | 建議 NVIDIA 顯示卡 8 GB 以上、記憶體 16 GB、硬碟 10 GB。沒有獨立顯卡也能跑，但回答很慢 |
| 上網查資料 | 不用另外裝東西（內建搜尋）。進階使用者想改用 Docker + SearXNG 的話：BIOS 要開啟 CPU 虛擬化，額外吃 2～4 GB 記憶體 |

### Mac 版

Mac 請用 `fatfish for mac` 資料夾。程式跟 Windows 版是同一份，只有安裝和打開的方式不一樣：

- 第一次使用雙擊 **`首次安裝.command`**（會打開「終端機」），步驟跟上面一樣，只是改用 Homebrew 裝 Python、ffmpeg 和 Deno，第一次要等 10～20 分鐘。Mac 說「無法驗證開發者」的話，照 `請先看我.txt` 放行一次就好。
- 裝好後從「應用程式」資料夾或 Spotlight 打開「藍色大肥魚控制面板」，打開後在 Dock 圖示上按右鍵 →「選項」→「保留在 Dock」。`控制面板.command` 是備用的打開方法。
- 這份說明裡寫 `.bat` 的地方，Mac 都是 `.command`；「開始功能表」是「應用程式」資料夾；「開機自動打開控制面板」在 Mac 上是登入時打開。
- 本機 AI 建議用 M 系列晶片、記憶體 16 GB 以上（Mac 的顯示卡跟系統共用記憶體）；Intel Mac 建議用線上 AI。
- Mac 只有開著、沒睡眠的時候本魚才會上線，要長時間掛著的話，到「系統設定」→「電池」或「能源」打開防止自動睡眠。
- 首次安裝會在資料夾裡建一個 `.venv`（本魚專用的 Python 環境），分享資料夾給別人時不用放進去。

執行後會自動產生這些資料檔，不要刪掉，換新版程式時也要保留：`config.json`（面板設定）、`guild_settings.json`（各種伺服器設定、警告紀錄）、`music_channels.json`、`levels.json`、`reminders.json`、`giveaways.json`、`fishing.json`（釣魚紀錄）。`guilds.json` 是機器人寫給控制面板看的伺服器清單，`command_sync.json` 是斜線指令的註冊紀錄，這兩個刪掉也沒關係，會自動重新產生。

如果資料夾裡還有 `dist`、`build` 資料夾或 `bluefish_bot.spec`，請全部刪掉，那是舊版打包出來的東西。

## 怎麼啟動：控制面板

從開始功能表或桌面打開「藍色大肥魚控制面板」（或雙擊 `控制面板.bat`），會打開一個視窗。控制面板同時只會開一個：已經開著的時候再點一次，會把原本那個叫到最前面。第一次打開新版面板時，它會自動在開始功能表放一個捷徑。

左邊的深藍色導覽列可以切換各頁（主控台、AI 來源、知識庫、伺服器、頻道功能、本機模型、設定、人設），最下面顯示本魚在幾個伺服器裡；右上角的膠囊顯示本魚現在的狀態（綠色上線中、黃色啟動中或在背景執行、灰色已停止）。

面板只會顯示你現在用得到的東西：用線上 AI 時「本機模型」這頁、「叫醒 Ollama」按鈕和「深度思考」選項都用不到，會自動藏起來；用內建搜尋時，SearXNG 和 Docker 的東西也會藏起來。換設定之後它們會自動出現。

面板支援高解析度螢幕：在 125%、150%、175% 這些顯示縮放下字都是清晰的，不會糊掉。視窗大小會配合螢幕自動調整，小螢幕的筆電也放得下。

**主控台**
- 上方四張狀態卡片：機器人、AI 聊天、上網查資料、點歌。左邊的顏色帶和圓點：綠色是正常，紅色是有問題，黃色是啟動中或勉強能用，灰色是沒用到（例如用線上 AI 時不需要 Ollama）。「AI 聊天」那張會顯示現在用的是本機 Ollama 還是哪個線上服務；「上網查資料」那張會顯示用內建搜尋還是 SearXNG；「點歌」那張會檢查放音樂要用的 ffmpeg 和解析 YouTube 要用的 Deno（或 Node.js）。缺東西的時候，下面的執行紀錄會用紅字告訴你怎麼補。
- 「🐟 本魚」卡片：「▶ 啟動」「■ 停止」「⟳ 重新啟動」控制機器人。
- 「🐟 邀請到伺服器」：打開邀請頁面，同時把邀請連結複製起來，可以直接貼給別人。
- 「AI 聊天：開／關」：按一下就切換，機器人執行中也會立刻生效，不用重新啟動。用本機 Ollama 時，關掉會把模型從顯示卡卸載（釋放大約 9 GB 顯示卡記憶體）。有人 @本魚 聊天會收到「AI 休息中」的提示；點歌、斜線指令、管理、等級這些功能都照常運作。AI 關著的時候啟動機器人，也不會去叫醒 Ollama 和 SearXNG。設定會記住，下次打開還是一樣。
- 用線上 AI 時不需要 Ollama，「AI 聊天」卡片會顯示藍色的「線上：服務名稱」，面板也不會再去檢查 Ollama。
- 「🧰 小工具」卡片（只會出現現在用得到的按鈕）：
  - 「🔄 更新元件」：第一次使用、或換了新版的本魚時按一下，會把本魚需要的元件（Python 套件）裝好或更新到最新版。
  - 「叫醒 Ollama」（用本機 AI 才會出現）、「叫醒 SearXNG」（用 SearXNG 搜尋才會出現）：狀態燈是紅的時候按，會自動幫你打開。
  - 「📂 打開本魚資料夾」。
  - 「強制關閉所有本魚」：本魚每句話都回兩次、或是關不掉的時候用，會把這台電腦上所有正在跑的本魚都關掉，包括舊版的 `bluefish_bot.exe`。
- 「📝 執行紀錄」：本魚在做什麼都寫在這裡，錯誤會用紅字標出來，右上角的「清除」可以清空。
- 機器人卡片如果顯示「在背景執行（別處開的）」，代表有一隻不是這個面板開的本魚殘留在背景。按「▶ 啟動」時面板會問你要不要先把它關掉。

**知識庫**（讓本魚參考你的資料，詳細說明看下面的「知識庫」段落）
- 「📂 開啟知識庫資料夾」打開資料夾，把文件放進去就好；「＋ 加入檔案…」可以直接挑檔案複製進去。側邊欄最下面也有「開啟知識庫資料夾」，在哪一頁都能一鍵打開。
- 表格列出每個檔案有沒有讀到、分成幾段；讀不到的（格式不支援、檔案壞掉、PDF 是掃描的圖片…）會用紅字寫原因。雙擊一列可以打開那個檔案。
- 「伺服器專用資料」：選一個伺服器按「建立資料夾」，放進那個資料夾的檔案只有那個伺服器能用。
- 「測試」：打一個問題按「搜尋」，看本魚會參考哪幾段資料，可以用來確認資料放對了沒。
- 「啟用知識庫」取消勾選就整個關掉；也可以在「頻道功能」頁針對個別頻道關掉。

**AI 來源**（選 AI 聊天用哪個「大腦」，改了立刻生效）
- 最上面三張卡片是最簡單的選法，正在用的那張外框是藍色、按鈕寫著「✔ 使用中」：
  - **🆓 免費線上 AI**：按「使用這個」就好，什麼都不用申請。缺點是大家共用，常要等 10～50 秒，人多時偶爾沒回應。
  - **⭐ Google Gemini（推薦）**：按「取得金鑰」→ 用 Google 帳號登入 → 按「Create API key」→ 按複製 → 回來按「貼上並使用」。面板會先測試金鑰能不能用，成功才存起來。
  - **💻 本機 Ollama**：按「使用這個」會直接帶你到「本機模型」分頁下載模型。
- 「▸ 進階設定」平常是收起來的，點一下才會展開（正在用三張卡片以外的服務時會自動打開）。可以選其他服務：DeepSeek、OpenAI（ChatGPT）、Anthropic Claude、OpenRouter、Groq，或任何支援 OpenAI 格式的服務（例如 LM Studio，選「自訂」才會出現「API 網址」欄位）。選好服務 → 按「取得金鑰」申請 → 貼上金鑰 → 按「抓模型清單」從下拉選單挑模型 → 按「測試連線」→ 按「✔ 儲存並套用」。
- 模型名稱各家更新得很快，**不確定要填什麼就按「抓模型清單」**，會列出那個服務現在能用的模型。
- 「提問上限」：用線上 AI 時，每個人每分鐘最多能問幾次（預設 5 次，0 = 不限），避免有人一直洗、把你的帳單刷爆。
- 金鑰存在 `ai_keys.json`，跟 Token 一樣不能給別人看。
- 用線上 AI 時，大家跟本魚聊天的內容會送到那個服務的伺服器。在意隱私的話用本機 Ollama。

**伺服器**
- 列出本魚所在的所有伺服器。選一個或好幾個（按住 Ctrl），按「✔ 啟用」或「✕ 停用」，雙擊一列也可以快速切換。**機器人執行中也會立刻生效。**
- 停用的伺服器裡，本魚不回任何訊息、不跑自動管理、等級、歡迎訊息和紀錄，正在放的音樂會停掉，斜線指令也會從那個伺服器收起來（重新啟用就會再出現）。
- 「新加入的伺服器自動啟用」：取消勾選的話，別人把本魚拉進新伺服器後，她會先安安靜靜待著，要你在這裡啟用才開始工作。適合把邀請連結公開出去時使用。
- 「讓本魚離開這個伺服器」：真的讓她退出。只是暫時不想讓她工作的話用「停用」就好。
- 「複製邀請連結」「用瀏覽器打開」：把本魚加到其他伺服器用。只要在「設定」填好 Token 就能用，不用等機器人啟動過。
- 伺服器清單是機器人上線時更新的，機器人沒在跑的時候會顯示上次的清單。

**頻道功能**（每個頻道可以個別關掉某些功能，改了立刻生效）
- 上面選伺服器，表格會照 Discord 的分類和順序列出所有頻道。
- 直接**點表格裡的 ✔／✕** 就能切換；點「📁 分類」那一列，會把整個分類一起切換（◐ 代表分類裡有開有關）。有關掉功能的頻道會變成橘色。
- 可以按住 Ctrl 選好幾個頻道，再按「選取的頻道全部開啟／關閉」。
- 可以個別開關的功能：AI 聊天、點歌、小遊戲、聊天經驗值、自動回覆、運動比分、知識庫。
- 管理類指令（踢人、警告、自動管理…）不受這裡影響，避免把自己鎖在外面。討論串會跟著它所在的頻道走，新開的頻道預設全部開啟。
- 第一次打開如果顯示「還沒有頻道清單」，啟動機器人一次就會出現。

**本機模型**（本機 Ollama 用的；用線上 AI 的話這頁用不到，會自動從選單藏起來）
- 列出推薦的模型，上方會自動偵測你的顯示卡。「你的電腦」欄會標示 ✅ 跑得動、⚠️ 會變慢、❌ 太大（放不進顯示卡的部分會改用 CPU 跑，回答會慢很多）。
- 選一個按「⬇ 下載」，下方會顯示進度、速度和剩餘時間。可以隨時「取消下載」，已下載的部分會保留，下次會接著下載。
- 下載好之後按「✔ 使用這個模型」（或直接雙擊那一列）就會換過去。機器人正在執行的話會立刻切換，不用重新啟動。
- 「🗑 刪除」可以刪掉用不到的模型，釋放硬碟空間。
- 清單裡沒有的模型：到「Ollama 模型庫」找，把名稱（例如 `qwen3:14b`）打在「其他模型」框裡按下載。自己裝的模型也會出現在清單裡。
- 有些模型不支援「深度思考」（清單裡標 ✘ 的），本魚碰到時會自動改用一般模式回答，不會壞掉。
- 顯示卡記憶體的需求是大約的數字；偵測只支援 NVIDIA 顯示卡，其他顯示卡會顯示「？」。

**設定**
- 分成三張卡片：「🔑 Discord 機器人」填 Token；「💬 聊天」設定記住幾輪對話、上網查資料和深度思考；「🚀 開機」設定要不要自動啟動。本機模型改到「本機模型」分頁選。
- 「記住最近幾輪對話」：越多越記得前面聊過什麼，但回答會稍微慢一點。
- 「上網查資料」：取消勾選的話 AI 就不上網查，只憑自己知道的回答（會跟使用者說資料可能過時）。
- 「搜尋方式」：**內建搜尋**（推薦）不用裝任何東西，會同時問 Google、Brave、DuckDuckGo、Yahoo、維基百科好幾家，哪家暫時擋我們就自動換下一家。**SearXNG** 是自己用 Docker 架的搜尋服務，選它才會出現「SearXNG 網址」和「Docker 位置」兩格；SearXNG 沒開的時候，本魚會自動改用內建搜尋。
- 「深度思考」（用本機 Ollama 才會出現）：勾起來回答比較準但比較慢；覺得本魚回太慢可以關掉試試看。
- 「打開控制面板時，自動啟動本魚」和「電腦開機時，自動打開控制面板」兩個都勾，開機後機器人就會自己上線。
- 「🐟 建立捷徑」：在開始功能表和桌面各放一個「藍色大肥魚控制面板」捷徑（本魚的大頭貼圖示），可以釘選到開始和工作列。捷徑不小心刪掉、或是 Python 換了位置時，按一下就會重建。（Mac 上這個按鈕是「🐟 建立 App」，在「應用程式」資料夾做一個「藍色大肥魚控制面板」。）
- 開機自動打開控制面板也是用同一種捷徑，開機時不會再閃一下黑色視窗。
- 改完按「儲存設定」，機器人正在跑的話會問你要不要重新啟動套用。

**人設**
- 直接編輯本魚的個性和規則，按「儲存人設」後重新啟動機器人就生效。
- 改壞了按「還原成預設人設」就能回到原本的版本。

第一次使用的順序：打開面板 → 按「小工具」裡的「更新元件」等它跑完 → 到「設定」確認 Token → 到「AI 來源」選 AI（不懂的話選「免費線上 AI」或「Gemini」）→ 回「主控台」按「▶ 啟動」。

關掉面板時，如果機器人還在跑，面板會問你要不要一起停止。

不想用面板的話，雙擊 `run.bat` 也能照舊用黑色視窗啟動。

## 怎麼跟她互動

- **伺服器頻道**：`@機器人` + 你的訊息，或直接**回覆**她的任何一則訊息
- **私訊**：不用 @，直接傳訊息
- 聊天時提到別人（例如「@本魚 你覺得 @小明 怎麼樣」），她看得到你說的是誰
- 她只看得懂文字，傳圖片會跟你說看不懂
- 打 `/幫助` 可以看到她所有的功能

**第一次用？在聊天框打 `/`，最上面的 `/-使用說明` 就是新手教學**，下面的選單可以切換看每一類功能（`/幫助` 也是同一份）。

她每次都會直接「回覆」你的那則訊息，就算很多人同時問，也看得出哪個回答是給誰的。

她會自己判斷每則訊息要怎麼處理，不需要特別下指令：

| 你問的東西 | 她會怎麼做 |
|---|---|
| 歌手、專輯、遊戲、產品、新聞、天氣等事實 | 自動上網查，照搜尋結果回答 |
| 「去查」「再確認一下」這種接續前文的話 | 會自動根據前面的對話補完要查什麼 |
| 「計算5000階乘」「給我1到100的隨機數」 | 用程式精確計算，結果太長會用檔案傳給你 |
| 「給我 Give Me Love 的連結」 | 去 YouTube 找真的連結給你 |
| 打招呼、閒聊、寫程式、食譜 | 直接聊，長的內容會一次寫完 |

### 控制面板與斜線指令

- **@ 她但什麼都不打**，或 `@機器人 選單`：跳出一排按鈕，上一首、暫停/繼續、下一首、重播、點歌、播放清單、停止都能直接按。按「點歌」會跳出小視窗讓你輸入歌名。面板 10 分鐘後會失效，再叫一次就好。
- **在聊天框打 `/`**：Discord 會列出本魚所有的指令，例如 `/點歌`、`/下一首`、`/上一首`、`/播放清單`、`/選單`，選了就能用，不用 @。

如果打 `/` 看不到本魚的指令，代表當初邀請機器人時沒給「建立斜線指令」的權限。到 Developer Portal 的 OAuth2 → URL Generator，Scopes 同時勾 `bot` 和 `applications.commands`，用新網址重新邀請一次（不用先踢掉她）。

### 點歌頻道（不用 @ 就能點歌）

有「管理頻道」權限的人，在想當點歌頻道的文字頻道裡打：

```

```

之後在這個頻道裡：

- 不用 @，直接打歌名就會點歌，例如只打 `告白氣球`
- `下一首`、`上一首`、`暫停`、`播放清單` 這些指令也可以直接打
- 想跟其他人聊天、不想被當成點歌，訊息開頭加 `//`，例如 `//這首好好聽`
- 有 @ 她的訊息，還是會照常用 AI 聊天

不想要了就打 `@機器人 取消點歌頻道`。設定會存在同一個資料夾的 `music_channels.json`，重開機器人也會記得。

**常駐點歌台**：設定好點歌頻道後，本魚會在頻道**最底下放一個點歌台**，上面顯示現在播放的歌、接下來的 5 首和循環模式，下面是所有控制按鈕。

- 點歌台的位置存在 `music_panels.json`，刪掉也沒關係，本魚會重新發一個。

## 伺服器管理功能

這些都是斜線指令，打 `/` 就會出現。管理類指令只有具備對應權限的人才看得到、才能用。

### 管理成員

| 指令 | 作用 | 需要的權限 |
|---|---|---|
| `/踢出 成員 原因` | 踢出伺服器 | 踢出成員 |
| `/封鎖 使用者 原因 刪除幾天內的訊息` | 封鎖，可順便刪他最近 0 到 7 天的訊息 | 封鎖成員 |
| `/解除封鎖 使用者id` | 用使用者 ID 解除封鎖 | 封鎖成員 |
| `/禁言 成員 分鐘數 原因` | 暫時不能說話，最多 28 天 | 禁言成員 |
| `/解除禁言 成員` | 提早解除 | 禁言成員 |
| `/清除訊息 數量 只刪這個人的` | 刪掉最近 1 到 100 則，可以只刪某人的 | 管理訊息 |

本魚會檢查身分組高低：不能對擁有者、自己、比你高或跟你同級的人出手；對方比本魚高的話本魚也動不了。

### 身分組

| 指令 | 作用 |
|---|---|
| `/身分組 給予 成員 身分組` | 幫人加身分組 |
| `/身分組 移除 成員 身分組` | 拿掉身分組 |
| `/身分組 面板 標題 身分組1～5` | 發一則有按鈕的訊息，大家按按鈕就能自己領或拿掉身分組 |
| `/自動身分組 新增／移除／查看` | 新成員一加入就自動給的身分組 |

也可以用說的：`@本魚 幫 @小明 加身分組 VIP`，身分組可以打名稱（大小寫、只打一部分都行）或直接 @ 那個身分組。

安全限制：你不能發比自己最高身分組還高的身分組；有管理權限的身分組（管理員、踢人、封鎖等）不能放進自助面板或自動身分組，避免誰都能拿到管理權限。

自助身分組面板在機器人重開後按鈕還是有效。

歡迎訊息可以用這些代號：`{user}` 會 @ 新成員、`{name}` 是他的名字、`{server}` 是伺服器名稱、`{count}` 是現在的成員數。不填就用本魚預設的可愛版本。

這些設定存在同一個資料夾的 `guild_settings.json`。

`/伺服器資訊`、`/成員資訊 成員`、`/頭像 使用者`、`/幫助`

`/歡迎 離開設定 頻道 訊息`、`/歡迎 離開關閉`。訊息可以用 `{name}`、`{server}`、`{count}`。

### 等級系統

大家聊天就會拿經驗值（每分鐘最多算一次，每次 15 到 25 點），升級時本魚會恭喜。預設是開啟的。

| 指令 | 作用 |
|---|---|

經驗值存在 `levels.json`，每分鐘自動存檔一次。

### 自動回覆

`/自動回覆 新增 關鍵字 回覆`：有人**整句剛好**說了關鍵字，本魚就自動回覆（可用 `{user}` 代表說話的人）。還有 `移除` 和 `查看`，最多 50 組。

### 提醒

`/提醒 設定 多久後 內容`，時間可以打 `10分鐘`、`2小時後`、`1天`、`1h30m`，最多 30 天。`/提醒 清單` 看自己的提醒，`/提醒 取消 編號` 取消。機器人重開後提醒不會消失（存在 `reminders.json`），但機器人沒開的期間到期的提醒，會等下次上線才送出。

### 投票

`/投票 問題 選項 幾小時後結束 可以複選`，選項用逗號分開，2 到 10 個。用的是 Discord 原生投票，結果會自動統計。

### 抽獎（要有「管理伺服器」權限）

`/抽獎 開始 獎品 時間 名額`，大家按按鈕參加，時間到自動開獎。`/抽獎 結束` 提早開獎，`/抽獎 重抽` 重新抽。不填訊息 ID 時，就是這個頻道最新的那個抽獎。機器人重開後抽獎還會繼續（存在 `giveaways.json`）。

### 客服單

在想放按鈕的頻道打 `/客服單 面板 客服身分組`。成員按「開啟客服單」，本魚會開一個只有他跟客服身分組（和管理員）看得到的私人頻道，處理完按「關閉客服單」就會刪掉。每個人同時只能開一張。本魚需要「管理頻道」權限。

### 動態語音

`/動態語音 設定 入口頻道`：有人進入口頻道，本魚就幫他開一間「某某的房間」並把他移過去，房主可以自己改名和設人數上限，房間沒人時自動刪掉。本魚需要「管理頻道」和「移動成員」權限。

### 精選板

`/精選 設定 頻道 門檻`：訊息收到足夠的 ⭐ 反應，就會自動轉貼到精選頻道。

### 遊戲

**釣魚**：`/釣魚` 拋竿後等浮標動了，**4 秒內按「收竿」**才釣得到，1.2 秒內收竿還會提高釣到稀有魚的機率。總共有 15 種收穫，分成垃圾、普通、稀有、史詩、傳說五種稀有度，傳說級的大約 70 次才出現一次（聽說還能釣到本魚的親戚）。每個人 30 秒只能釣一次。`/魚缸` 可以看自己或別人的圖鑑收集進度和最大紀錄，`/釣魚排行` 看伺服器前 10 名。釣魚資料存在 `fishing.json`。

**井字棋**：`/井字棋` 不填對手就是跟本魚下（本魚很強，但偶爾會手滑）；填了對手會先送出挑戰，對方按「接受挑戰」才開始，先手隨機決定。

**21 點**：`/21點` 跟本魚玩 Blackjack，按「要牌」或「停牌」，本魚會補牌補到 17 點以上。

**猜數字**：`/猜數字` 本魚想一個 1 到 100（可以自己設最大值）的數字，頻道裡所有人都能按「我要猜！」一起猜，本魚會說太大還是太小，範圍會越縮越小。一個頻道同時只能有一局。

這些遊戲按鈕只有該局的玩家按得到，別人按會收到只有自己看得到的提示。機器人重新啟動的話，進行中的井字棋、21 點、猜數字會失效，釣魚紀錄不會受影響。

**小遊戲**：`/擲骰 2d6`、`/擲硬幣`、`/選擇 火鍋,燒烤,拉麵`、`/占卜 問題`、`/猜拳`

### 知識庫（讓 AI 參考你的資料）

把文件放進程式資料夾裡的 **`知識庫`** 資料夾（控制面板的「知識庫」頁或側邊欄可以一鍵打開），本魚跟大家聊天時就會自動參考：

- **支援的格式**：txt、md、PDF、Word（docx）、Excel（xlsx）、PowerPoint（pptx）、csv、json、網頁（html）、程式碼。舊版的 doc、xls 請先另存成新格式。掃描成圖片的 PDF 讀不到文字。
- **怎麼運作**：每則訊息本魚會先在知識庫裡找相關的段落（繁體、簡體都找得到，常見的同義詞像「規定／規則」、「價格／費用」也會一起找），找到就交給 AI 照著資料回答。知識庫裡就有答案的話，本魚不會再上網查，比較快也不會跟網路資料打架（問「今天」「最新」這種有時間性的問題例外）。
- **資料來源**：回答真的用到資料時，最後會用小字標出「📚 資料來源：檔名」。
- **本機、線上 AI 都能用**，不用另外下載模型，找資料完全在你電腦上進行、不花額度。
- **改了檔案不用重開機器人**，大約 20 秒內會自動重新讀取。
- **伺服器專用資料**：資料夾名稱裡有 `[伺服器ID]` 的，裡面的檔案只給那個伺服器用（控制面板按「建立資料夾」會自動幫你取好名字）；其他檔案所有伺服器和私訊都能用。
- **暫時停用某個檔案**：在檔名前面加 `_`（例如 `_草稿.txt`），就不會被讀取。
- **每個頻道可以個別關掉**：控制面板「頻道功能」頁的「知識庫」欄。
- `/知識庫 搜尋 關鍵字`：直接查資料，不經過 AI。`/知識庫 清單`：看有哪些資料。

小技巧：用清楚的標題（Markdown 的 `#` 標題、Word 的標題樣式）和分段，本魚比較容易找到正確的那一段；表格的第一列寫欄位名稱。

⚠ 放進知識庫的內容，本魚可能會在聊天時說出來，**不要放密碼、個人資料這些不能公開的東西**。

### 機器人需要的權限

最簡單的做法是給本魚「管理員」權限（你已經給了）。如果不想給管理員，至少要有：管理身分組、管理頻道、踢出成員、封鎖成員、禁言成員、管理訊息、讀取訊息紀錄、新增反應、移動成員、連接、說話。

另外，**本魚的身分組要拖到她需要管理的那些身分組上面**，不然就算有權限也動不了。

### 播放方式

點歌時，本魚會先把歌下載到資料夾裡的 `music_cache`，下載好才開始放。新歌開始前會多等一兩秒，但播放中不會因為網路忽快忽慢而卡頓。

解析 YouTube 影片要用 JavaScript 執行環境解開 YouTube 的「驗證題」：本魚會自動找電腦裡的 Deno（首次安裝會幫你裝）、Node.js 或 Bun，找到哪個用哪個，啟動時執行紀錄會寫「YouTube 解析使用 …」。

本魚會記住「點歌文字／網址 → 哪首歌」：**同一首歌再點一次（就算隔天、重開機器人之後）會直接用暫存的檔案，幾乎不用等**。暫存最多留 60 首，最久沒播的會自動刪掉；上次沒下載完的殘檔會在啟動時清掉。想整個清空的話，關掉機器人後刪掉 `music_cache` 資料夾就好，會自動重建。超過 3 小時的影片不能點。

### 語音頻道自動離開

- 語音頻道裡的人都走光後，本魚 1 分鐘後會自己離開。
- 佇列放完、5 分鐘都沒有新歌，本魚也會自己離開。

## 進階設定（config.json）

面板沒有的設定可以直接用記事本打開 `config.json` 加上去，改完重新啟動機器人：

| 設定 | 預設 | 說明 |
|---|---|---|
| `"ollama_keep_alive"` | `"30m"` | 模型閒置多久才從顯示卡卸載。想讓模型一直待在顯示卡裡就填 `-1`；顯示卡記憶體不夠、要玩遊戲的話改小一點，例如 `"5m"` |
| `"ollama_host"` | 空的 | Ollama 不在這台電腦上時才要填，例如 `"http://192.168.1.10:11434"` |
| `"enable_thinking"` | `true` | 等於面板的「深度思考」 |
| `"ai_enabled"` | `true` | 等於面板的「AI 聊天：開／關」 |
| `"ai_provider"` | `"ollama"` | 等於面板「AI 來源」選的服務：`ollama`、`free`、`gemini`、`deepseek`、`openai`、`claude`、`openrouter`、`groq`、`custom` |
| `"ai_user_limit"` | `5` | 等於面板「AI 來源」的提問上限 |
| `"knowledge_enabled"` | `true` | 等於面板「知識庫」頁的「啟用知識庫」 |
| `"search_engine"` | `"builtin"` | 等於面板「設定」的「上網查資料方式」：`builtin`（內建搜尋）或 `searxng`。舊的設定檔沒有這一項時，有開上網查資料的話照舊用 SearXNG |

## 建立新的機器人時要注意

如果是自己新建一個 Discord 機器人來用（例如把本魚分享給朋友），到 Developer Portal → 你的應用程式 → Bot，**一定要打開「Message Content Intent」和「Server Members Intent」**，不然機器人一啟動就會出錯關掉。

## 常見問題

**本魚沒有用到知識庫裡的資料**
到控制面板「知識庫」頁：先看那個檔案的「狀態」是不是「✔ 可以用」；再用「測試」打同一個問題，看找不找得到。找不到的話，試著在資料裡用跟大家提問時一樣的說法（例如大家都說「VIP」，資料就寫「VIP」），或加個清楚的標題。PDF 讀不到的話，到主控台按一次「小工具」裡的「更新元件」（需要 pypdf）。

**本魚用本機 AI 回答很慢**
新版已經修掉一個拖慢速度的問題（以前每則訊息都會讓 Ollama 重新載入模型兩次，14b 模型每則白等 6 秒多）。還是覺得慢的話：到「設定」把「深度思考」關掉（快很多，但比較容易答錯）、到「本機模型」換小一點的模型，或到「AI 來源」改用線上 AI。

**用「免費線上 AI」時本魚回很慢，或回「現在太多人在用」**
免費服務是大家共用的，常常要排隊。想要快又穩，到控制面板「AI 來源」分頁改用 Google Gemini（也是免費的，只要用 Google 帳號拿一把金鑰）。

**線上 AI 說金鑰不對、額度用完、找不到模型**
到控制面板「AI 來源」分頁：金鑰不對就重新複製貼上（前後不要有空白）；額度用完要到那個服務的官網儲值；找不到模型就按「抓模型清單」重新挑一個，再按「測試連線」確認。

**想把本魚分享給朋友**
把整個資料夾複製一份給他之前，**一定要先刪掉 `token.txt` 和 `ai_keys.json`**（你的 Discord Token 和 AI 金鑰），也可以順便刪掉 `guild_settings.json`、`levels.json` 這些你伺服器的資料。朋友要自己建一個 Discord 機器人（見下一段），再雙擊 `首次安裝.bat`。

**按「■ 停止」要等幾秒**
新版會先請本魚自己安全關機（存好等級資料、離開語音頻道），最多等 12 秒，還沒關好才強制結束。

**每句話都回兩次，或是點歌一直斷斷續續**
代表有兩隻本魚同時在跑。打開控制面板按「小工具」裡的「強制關閉所有本魚」，再按「▶ 啟動」。新版本魚啟動時會自己檢查，已經有一隻在跑就不會再開第二隻。

**雙擊 `run.bat` 視窗一閃就關掉**
在資料夾空白處按住 Shift 再按右鍵，選「在終端機中開啟」，輸入 `.\run.bat` 執行，就能看到錯誤訊息。最常見的原因是沒裝 Python 或沒加進 PATH。

**卡在檢查 Ollama 或 SearXNG**
手動打開 Ollama 和 Docker Desktop，等它們正常運作後重新執行 `run.bat`。不想管 Docker 的話，到「設定」把「上網查資料方式」改成「內建搜尋」就不需要它了。

**YouTube 點歌失敗，或執行紀錄出現「No supported JavaScript runtime」**
YouTube 會出「驗證題」，要用 Deno（或 Node.js）才解得開。再雙擊一次 `首次安裝.bat`，它會幫你下載 Deno；裝好後在控制面板重新啟動機器人。還是不行的話，按「小工具」裡的「更新元件」把負責下載影片的 yt-dlp 更新到最新版（YouTube 常常改版，yt-dlp 也會跟著更新）。

**上網查資料常常查不到東西**
內建搜尋是去問 Google、Brave 這些搜尋引擎，短時間內問太多次會被暫時擋住，通常幾分鐘後就恢復。在控制面板按「小工具」裡的「更新元件」可以更新搜尋元件（ddgs）。常常要查資料的話，也可以改用 Docker + SearXNG。

**點歌沒聲音，或出現 opus 相關錯誤**
到 discord.py 官方文件搜尋 `libopus`，把對應的 DLL 放到跟 `run.bat` 同一層。

**名字旁邊的「應用」標籤能不能拿掉**
不行，Discord 規定所有機器人帳號都會顯示這個標籤。

**想改她的個性**
打開控制面板的「人設」分頁直接改，儲存後重新啟動機器人就生效。

**面板打不開，雙擊沒反應**
在資料夾空白處按住 Shift 再按右鍵，選「在終端機中開啟」，輸入 `python panel.pyw`，就能看到錯誤訊息。如果訊息提到 `tkinter`，代表安裝 Python 時沒勾選「tcl/tk and IDLE」，重新執行 Python 安裝程式、選「Modify」把它勾起來就好。
