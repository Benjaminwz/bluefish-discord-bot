藍色大肥魚 Discord 機器人（Mac 版）
==================================

需要：macOS 13 以上、網路。不用先裝任何東西。
（這份是 Mac 版的說明；Windows 的步驟不一樣，請看 Windows 版的說明。）


【第一次使用，照這三步做】

1. 先建立一個 Discord 機器人（大約 3 分鐘）
   ① 打開 https://discord.com/developers/applications ，按「New Application」取個名字
   ② 左邊選「Bot」，按「Reset Token」，再按複製（等一下要貼）
   ③ 同一頁往下，把「Message Content Intent」和「Server Members Intent」打開，按「Save」
      （沒打開的話，機器人一啟動就會關掉！）

2. 雙擊「首次安裝.command」
   會打開「終端機」，照畫面回答問題，直接按 Enter 就是「好」。
   它會用 Homebrew 裝好 Python、ffmpeg 這些需要的東西（第一次要等 10～20 分鐘），
   問你 AI 聊天要用哪一種（不懂的話直接按 Enter，用免費線上 AI），
   最後把剛剛複製的 Token 貼上（按 Command + V）。
   要輸入密碼時，就是這台 Mac 的登入密碼（打字時畫面不會顯示，打完按 Enter）。

3. 在控制面板按「▶ 啟動」
   首次安裝完會自動打開控制面板，之後從「應用程式」資料夾或 Spotlight 搜尋「藍色大肥魚」打開
   （圖示是本魚的大頭貼；打開後在 Dock 圖示上按右鍵 →「選項」→「保留在 Dock」就能常駐）。
   按「🐟 邀請到伺服器」把本魚加進你的伺服器，
   在 Discord 聊天框打 /-使用說明 就能看到新手教學。


【Mac 說「無法打開」或「無法驗證開發者」怎麼辦】

這個程式沒有付錢給 Apple 認證，第一次打開時 Mac 會擋下來，照這樣放行就好（只要做一次）：
- macOS 15 以上：按「完成」→ 打開「系統設定」→「隱私權與安全性」→ 拉到最下面，
  按「首次安裝.command」旁邊的「仍要打開」→ 輸入密碼 → 再按「打開」。
- macOS 14 以下：在「首次安裝.command」上按右鍵 →「打開」→ 再按一次「打開」。
- 還是不行的話：打開「終端機」，輸入 bash 加一個空白，把資料夾裡的 setup.sh 拖進終端機視窗，按 Enter。
首次安裝跑完之後，這個資料夾裡的東西就不會再被擋了。


【常見問題】

- 本魚只有在 Mac 開著、沒有睡眠的時候才會上線。想讓它一直在線上：
  「系統設定」→「電池」（桌機是「能源」）→ 打開「電源轉接器接上時，防止自動進入睡眠」。
- AI 回很慢或常常沒回應：到控制面板的「AI 來源」分頁，照「Google Gemini」卡片上的步驟
  拿一把免費金鑰，又快又穩。
- 資料夾不要改名字或搬走，不然「應用程式」裡的圖示會打不開；真的搬了的話，
  雙擊「控制面板.command」打開，到「設定」按「建立 App」就會重新做一個。
- 更詳細的說明都在 README.md（用「文字編輯」打開就能看；裡面寫 .bat 的地方，Mac 是 .command）。


【注意】

- 把這個資料夾分享給別人之前，一定要先刪掉 token.txt 和 ai_keys.json
  （裡面是你的 Discord Token 和 AI 金鑰，別人拿到就能控制你的機器人、用你的額度）。
  .venv 資料夾是這台 Mac 專用的 Python 環境，也不用分享，對方跑首次安裝會自己建。
