藍色大肥魚

軟萌可愛的繁體中文 Discord 機器人：會聊天、會上網查資料、會點歌，還能幫你管伺服器。附圖形控制面板，Windows 和 Mac 都能用。

⬇ 免費下載 在 GitHub 查看 版本紀錄

她會做什麼

💬 AI 聊天

記得最近的對話，私訊不用 @ 就能聊。可以用免費線上 AI、Google Gemini、ChatGPT、Claude，或電腦上的 Ollama。

🔎 上網查資料

問到新聞、天氣、最新消息會自己先上網查，不用另外安裝搜尋服務。

🎵 點歌

YouTube、B 站都能點，有播放卡片、進度條和播放清單，也能設定專用的點歌頻道。

📚 知識庫

把伺服器規則、常見問題、攻略丟進資料夾，本魚回答時會自動參考，還會標出處。

🛡️ 伺服器管理

身分組、警告、歡迎訊息、紀錄頻道、等級、投票、抽獎、提醒、小遊戲。

🏀 運動比分

中職、台灣職籃、NBA、MLB、足球的比分和新聞。

三步驟開始用

  1. 到 Discord Developer Portal 建立一個機器人，複製它的 Token，並打開「Message Content Intent」和「Server Members Intent」。
  2. 按上面的「免費下載」，解壓縮後雙擊 首次安裝.bat（Mac 是 首次安裝.command），照畫面回答問題、貼上 Token。
  3. 在控制面板按「▶ 啟動」，再按「邀請到伺服器」，在 Discord 打 /-使用說明 看新手教學。
